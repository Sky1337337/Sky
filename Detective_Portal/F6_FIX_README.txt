F6 AUTO FIX — виправлення проблеми «водить курсором, але не вписує текст».

Зміни:
- Спочатку введення через Windows UI Automation (ValuePattern).
- Якщо воно не працює, введення через фокус поля і Ctrl+V.
- Після КОЖНОГО поля перевіряється фактичний текст; якщо поле порожнє, запит НЕ запускається.
- Координати не зберігаються та не налаштовуються.

Як запустити:
1) Розпакуй у НОВУ папку.
2) У PowerShell з папки Detective_Portal:
   py -m pip install -r requirements.txt
   $env:Path = "C:\Program Files\Tesseract-OCR;" + $env:Path
   py main.py
3) Telegram ліворуч, вебформа Edge праворуч, натисни F6.

ВАЖЛИВО: тестування на внутрішній вебформі у цьому середовищі неможливе.
Не використовуй результат OCR без звірки з джерелом для офіційних даних.
