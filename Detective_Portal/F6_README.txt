ТЕСТ F6 — ВОЄННИЙ ЗЛОЧИНЕЦЬ

1. Встановіть залежності: pip install -r requirements.txt
2. Встановіть Tesseract OCR для Windows, додайте файли rus.traineddata та ukr.traineddata. Якщо Tesseract не в PATH, створіть war_crime_config.json з {"tesseract_path": "C:\\Program Files\\Tesseract-OCR\\tesseract.exe"}.
3. Запустіть run.bat або python main.py. Старий EXE в dist НЕ містить нової функції: для EXE треба зібрати програму заново через build_detective_portal.bat.
4. Відкрийте браузер з джерелом ліворуч та форму «Воєнний злочинець» праворуч, як на скриншоті.
5. В програмі відкрийте «Воєнний злочинець (F6)» > «Налаштувати координати». По черзі натисніть кнопки, наведіть курсор на потрібне поле в Edge, зачекайте 4 секунди. Для кнопки «Знайти» так само.
6. Виведіть на екран текст з ПІБ та датою народження, натисніть F6. OCR розпізнає ЛІВІ 54% екрана. Перевірте український ПІБ у вікні підтвердження. Після «Так» програма заповнить ВЕРХНІ поля пошуку і натисне «Знайти».
7. Якщо сайт показує JavaScript-повідомлення «По запиту даних не знайдено», модуль пробує підтвердити його клавішею Enter за умови, що діалог активний. Форма сайту сама визначає, що відбудеться далі. Нові записи програма не зберігає.

ВАЖЛИВО: OCR та перетворення російських ПІБ не завжди точні. Перед відправленням пошуку підтвердьте правильність результатів. Функція не встановлює винуватість особи.
