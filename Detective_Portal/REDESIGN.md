# Оновлення інтерфейсу

Компактна панель 1000×650, спільна графітово-бірюзова палітра, швидке завантаження Excel, оновлене вікно F6.

Виправлення: безпечна навігація під час обробки подій; журнал зберігається між сторінками; нова таблиця скидає індекс; перевірка порту та затримки без часткового збереження; захист від паралельних операцій; закриття без модуля keyboard; збірка без особистого шляху Python.

## Запуск на Windows
Python 3.11–3.13. У папці програми:
```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```
Для EXE активуйте .venv і запустіть build_detective_portal.bat.
OCR потребує Tesseract з українською й російською мовами. Портал потребує чинного доступу та Chrome. Глобальні F6/F7, OCR, взаємодія з порталом і EXE у Linux не перевірені.

## Перевірка
6 тестів інтерфейсу пройшли у віртуальному дисплеї Linux. Для повтору встановіть pytest та запустіть `python -m pytest -q` із цієї папки при доступному графічному дисплеї. Вікна також відкрито вручну програмним запуском. У хмарному Linux відсутній повноцінний рендеринг Segoe UI, тому візуальна перевірка шрифтів потрібна на Windows.
