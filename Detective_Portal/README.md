# AutoFormFill Pro 2.0

Оновлена версія програми для завантаження Excel, підключення Chrome через Selenium, автоматичного заповнення форм та аналізу номерів.

## Запуск
1. Встановіть Python 3.11–3.13.
2. Запустіть `run.bat`.
3. У програмі завантажте Excel і натисніть **Підключити Chrome**.

## Збірка EXE
Запустіть `build.bat`. Готовий файл з'явиться у `dist\AutoFormFill Pro.exe`.

## Формат основного Excel
Перший рядок — заголовки. Дані з другого рядка:
1. Прізвище
2. Ім'я
3. По батькові
4. Дата народження
5. Телефон
6. Адреса

## Гаряча клавіша
`F8` — заповнити один наступний запис.

## Нові можливості
- сучасний інтерфейс;
- світла і темна тема;
- заповнення одного або всіх записів;
- пауза та зупинка;
- логування в папку `logs`;
- скріншоти помилок у `screenshots`;
- збереження налаштувань;
- результат аналізу в окремий Excel;
- автоматична установка ChromeDriver.
