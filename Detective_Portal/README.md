# Helper НПУ

Програма для роботи з Excel, заповнення форм через Chrome, аналізу номерів, роботи з картками F6/F7 та пошуку відповідей в освітніх матеріалах.

## Запуск на Windows

1. Установіть Python 3.11–3.13.
2. Розпакуйте всю папку програми та запустіть `run.bat`.
3. Для нового розділу виберіть **«Освітній портал»** у лівому меню.

Або виконайте в папці програми:

```bat
python -m pip install -r requirements.txt
python main.py
```

## Освітній портал

Усі **7 блоків, 2302 запитання й відповіді, 210 фото, схем і таблиць** включені в програму. Вставте текст і натисніть **«Знайти відповідь»**, або вставте скриншот запитання з фото через **Ctrl+V**. Є вибір блоку, перегляд матеріалів, копіювання відповідей та збільшення зображень.

Пошук працює локально. Для читання тексту зі скриншотів потрібен **Tesseract OCR з українською мовою `ukr`**. За текстом можна шукати без нього. Однакові формулювання з різними відповідями показуються окремо для порівняння.

[Детальна інструкція та налаштування OCR](EDUCATION_PORTAL.md).

## Робота з Excel

Підключіть Chrome та завантажте Excel. Перший рядок таблиці містить заголовки; дані починаються з другого:

1. Прізвище
2. Ім’я
3. По батькові
4. Дата народження
5. Телефон
6. Адреса

Доступні заповнення одного запису або пакета, пауза, зупинка, журнал подій і збереження результатів аналізу в окремий Excel. `F8` заповнює один наступний запис. Для роботи з картками використовуйте `F6`/`F7`; див. відповідні інструкції у папці програми.

## Збірка EXE

На Windows установіть залежності та запустіть `build_detective_portal.bat` — результат `dist\Helper НПУ.exe`. Альтернативний `build.bat` створює `dist\Detective Portal.exe`. Обидва варіанти включають освітню базу та фото. Tesseract установлюється окремо.

## Перевірка

Установіть `pytest` та виконайте `python -m pytest -q` з доступним графічним дисплеєм. Перевірки охоплюють інтерфейс, навігацію, базу запитань, текстовий пошук, зіставлення фото та вставлення з буфера обміну. Windows EXE слід збирати й перевіряти на Windows.
