F6 AUTO — тестова збірка, без ручних координат та вікна підтвердження.

1. У папці Detective_Portal виконай: py -m pip install -r requirements.txt
2. Встанови Tesseract OCR з мовами rus та ukr.
3. Запусти з PowerShell: $env:Path = "C:\Program Files\Tesseract-OCR;" + $env:Path
   Потім: py main.py
4. Розмісти джерело Telegram зліва та форму Edge праворуч; натисни F6.
5. Програма мінімізує своє вікно, читає видимий текст, знаходить пошуковий рядок через Windows UI Automation, заповнює і натискає «Знайти».

ОБМЕЖЕННЯ: невідомий HTML внутрішньої форми. Якщо Edge не публікує поля в UI Automation, буде повідомлення про необхідність HTML-атрибутів. Для надійного рішення потрібні селектори з DevTools цієї сторінки. OCR/транслітерація можуть помилятися; перед використанням результату для офіційного обліку звір дані з джерелом. Нові картки не зберігаються.
