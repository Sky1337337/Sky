F6 CAPS KEYBOARD TEST

Змінено тільки введення чотирьох полів верхнього пошуку F6:
- ПІБ друкується ВЕЛИКИМИ літерами, а не вставляється через Ctrl+V.
- Дата вводиться клавішами без змін у форматі.
- Unicode клавіші передаються через SendInput, тому не потрібно перемикати розкладку.
- Перед натисканням «Знайти» перевіряється точна відповідність введеного тексту.

F7, розпізнавання, фото, буфер фото, логіка нової картки не змінювалися.
Запуск: py main.py
